# README: Graph Data Structures and Union-Find

## 📌 Purpose and Aim

This project defines data structures for representing graphs and provides a **Union-Find (Disjoint Set)** helper function. The main aim is to:

* Represent a graph using an adjacency matrix.
* Store traversal-related attributes for each vertex (for BFS/DFS and SCC algorithms).
* Provide a **union-find `find` function** to support graph algorithms like **Kruskal's Minimum Spanning Tree (MST)** or connectivity checks.

The **Union-Find algorithm** is used to efficiently manage disjoint sets, particularly in applications like cycle detection and MST construction.

---

## ⚙️ Algorithm in Brief: Union-Find (Disjoint Set)

Union-Find (or Disjoint Set Union, DSU) is a data structure that supports two main operations:

* **Find(x):** Determine the root representative of the set containing element `x`.
* **Union(x, y):** Merge the sets containing elements `x` and `y`.

In this code, only the **Find** operation is implemented. It works by following the `pred` (predecessor/parent) pointers until reaching the root of the set (a vertex that points to itself).

This is particularly useful in graph algorithms like Kruskal’s algorithm for MST, where we need to check whether two vertices belong to the same connected component.

```c
static int union_find_find(graph_t *g, int k) {
    int i = k;   // Start from the given vertex index
    while (i != g->g[i].pred) {
        i = g->g[i].pred;  // Move up the parent chain
    }
    return i;  // Return the root representative
}
```

* Implements the **Find operation**:

  * Starts from vertex `k`.
  * Follows the chain of predecessors (`pred`) until reaching the root (where `pred[i] == i`).
  * Returns the root index.
